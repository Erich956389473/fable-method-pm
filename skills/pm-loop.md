# pm-loop — 自适应产品执行循环

## 输入

- `decision`：pm-method 输出的决策路径
- `risk`：风险等级（可选，默认 mid）
- `stage`：产品阶段（可选，默认 growth）
- `deadline`：截止时间（可选）

## 自适应逻辑

### 1. 证据收集 — 根据产品阶段

**0-1 阶段：**
- 收集清单：用户访谈 3-5 人 + 竞品分析
- 不接受纯数据方案（没有数据）
- 时间盒：1 周内完成

**Growth 阶段：**
- 收集清单：数据看板 + 用户反馈 + 竞品
- 最少 2 类证据
- 时间盒：2 周内完成

**Mature 阶段：**
- 收集清单：AB测试 + 用户调研 + 数据模型
- 需要统计显著性
- 时间盒：1 个月内完成

### 2. INTENT 格式 — 根据受众自适应

**给 boss 看：**
```
INTENT（精简版）：
  问题：一句话
  决定：一个方案
  预期：一个数字
```

**给 team 看：**
```
INTENT（完整版）：
  问题：背景 + 现状
  证据：数据 + 用户声音
  决定：方案 + 验收标准
  风险：什么情况下停
  时间：时间线
```

**给自己看：**
```
INTENT（速记版）：
  做什么？
  凭什么？
  什么时候完？
```

### 3. 执行节奏 — 根据紧急程度

**Critical：**
- 跳过计划，直接执行
- 每 30 分钟同步一次
- 止血后再复盘

**Urgent：**
- 简化计划，最快路径交付
- 每日同步
- 交付后再补完整文档

**Normal：**
- 标准流程
- 周同步
- 完整文档

### 4. 验证深度 — 根据风险等级

**Low risk：**
- 上线即算验证
- 观察 3 天无异常即可

**Mid risk：**
- AB测试或前后对比
- 观察 1-2 周

**High risk：**
- 灰度发布 + AB测试
- 观察 1 个月 + 统计显著性验证
- 回滚方案准备
