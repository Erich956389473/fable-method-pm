# pm-judge — 自适应产品验证器

## 输入

- `decision`：待验证的决策/假设（必填）
- `decisionType`：决策类型（可选，默认 feature / feature / pricing / strategy / experiment）
- `risk`：风险等级（可选，默认 mid）
- `evidence`：已有证据（可选）

## 自适应逻辑

### 1. 对抗强度 — 根据决策类型

**Feature 决策（功能迭代）：**
- 替代解释数量：2 个
- 验证方法：AB测试或前后对比
- 接受标准：p<0.05 或明确趋势

**Pricing 决策（定价调整）：**
- 替代解释数量：4 个
- 验证方法：多组AB测试 + 用户调研
- 接受标准：p<0.01 + 定性验证

**Strategy 决策（战略方向）：**
- 替代解释数量：5 个
- 验证方法：多方验证 + 外部数据 + 专家评审
- 接受标准：多个独立证据来源一致

**Experiment 决策（实验）：**
- 替代解释数量：1 个
- 验证方法：快速验证
- 接受标准：有方向性信号即可

### 2. 假设跟踪 — 自动分类

不是所有假设都值得跟踪到天荒地老。根据重要程度分类：

**P0 假设（核心假设）：**
- 如果不成立，整个方案作废
- 跟踪到被验证或证伪为止
- 需要汇报给决策者

**P1 假设（重要假设）：**
- 如果不成立，方案需要调整
- 跟踪 3 轮验证
- 记录结论即可

**P2 假设（优化假设）：**
- 如果不成立，不影响核心方案
- 验证 1 次即可
- 结论记录到笔记

### 3. 输出格式 — 根据受众

**Boss：**
```
## 验证摘要
结论：✅ 建议继续 / ❌ 建议停止
关键证据：[1句话]
风险：[1句话]
```

**Team：**
```
## 验证报告
### 核心结论
### 验证过程
### 替代解释
### 悬而未决
### 建议
```

**Self：**
```
没通过？→ 原因
通过了？→ 下步
```
